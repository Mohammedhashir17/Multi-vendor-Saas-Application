# Bazario customer frontend

Create React App + Tailwind. Run `npm install`, then `npm start`.

Download Stitch image assets into `public/images` (updates `src/data/localImageMap.json`):

```bash
npm run download-images
```

Ensure the `Customer UI/stitch_modern_multi_vendor_marketplace_ui` folder exists next to `Multi-Vendor-Saas-App` in the parent directory.
